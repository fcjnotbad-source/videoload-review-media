iPhone 隐私说明

隐私政策

适用于 iPhone 版 VideoLoad No Ads，应用标识为 com.fcj.videoload.ios。本政策不用于描述 Android 版本。

更新日期：2026-11-10

1. 应用与您的数据

iPhone 版无需注册应用账号或登录，不包含广告、统计或跟踪 SDK。应用不会把您的视频或浏览历史副本上传至开发者运营的服务器，我们也不出售您的个人数据。

视频处理、片段标注、缩略图生成和购买权益验证在设备本地进行。Apple 及您主动使用的网站或服务仍会处理下文说明的请求。

2. 保存在设备上的信息

本地数据包括浏览标签、页面地址和标题、历史、收藏、Cookie、下载地址和来源页信息、下载断点、下载或导入的媒体、缩略图、标注、播放位置及偏好设置。为访问下载来源，任务可能保留所需的 Cookie、浏览器信息和来源页等请求信息。

开启隐私锁后，加盐派生的密码校验值保存在本机钥匙串。设备身份验证由 Apple 处理，应用不会取得 Face ID 或 Touch ID 的生物特征模板。隐私锁控制应用界面访问，不会加密您的媒体文件。

3. 浏览网页与下载

打开网站、提交搜索或下载文件会向相应网站、搜索引擎或媒体服务器发送请求。这些服务可能收到您的 IP 地址、页面或资源地址、浏览器信息、相关 Cookie 及您主动提交的内容。新的浏览会话可能首先打开 Google。第三方网站适用各自的隐私政策。

媒体识别在网页内本地运行，用于发现可播放资源的地址。下载直接联系资源来源，不通过开发者服务器中转视频。本地 HLS 播放使用仅绑定设备 127.0.0.1 的临时 HTTP 地址，并使用难以猜测的会话路径及本地文件白名单，不是公开上传服务。

4. 权限、导入与分享

相册和文件导入通过 Apple 的系统选择器，仅访问您选择的项目或目录。把导出的视频或 GIF 保存到相册时，会申请仅添加照片的权限。Face ID 或设备身份验证为可选功能，用于解锁隐私锁。应用不申请麦克风、相机、定位、通讯录或广告跟踪权限。

分享、导出或另存文件时，您选择的目标会收到该副本。您选择的文件提供方、iCloud 存储或设备备份设置，可能将应用数据或导出文件保存至您的 Apple 账户；这些存储由您和 Apple 或所选服务提供方控制，不属于开发者媒体云服务。

5. App Store 购买

Pro 是 App Store 的非消耗型一次性购买。支付、购买记录、退款及恢复由 Apple 按其政策处理。应用读取经过验证的 StoreKit 交易状态以开放功能；开发者不接收您的银行卡资料，也不运营独立支付账号。

6. 保留与删除

本地媒体和记录会保留至您删除，或系统移除应用数据。仅删除记录不一定删除原文件，请使用应用中的删除文件选项，并检查您另行导出的副本。您可在设置中清除浏览历史、WebKit 浏览器 Cookie 或缓存。

复制到系统下载存储中的 Cookie 可能独立保留，直至到期或应用数据被移除。清除浏览器 Cookie 不保证已有下载被取消或退出登录；不再需要的传输请在下载页取消。

在已解锁状态下关闭隐私锁，可移除其钥匙串校验值。卸载会移除应用容器，但导出副本、备份和钥匙串项目可能适用不同的 Apple 保留规则。开发者无法远程擦除仅在您设备上的数据，或其他服务保存的副本。

7. 本网站与可选支持

本网站托管于 GitHub Pages。加载页面、图标或演示文件会向 GitHub 托管基础设施发送普通网页请求信息。这些页面没有广告或统计脚本，也不设置应用 Cookie。其托管服务适用 GitHub 隐私声明。

您选择联系支持或提交公开 GitHub 问题时，相关服务和开发者会收到您主动提供的信息，用于答复请求。公开问题对他人可见，请勿提交密码、私人视频、购买凭据或其他敏感信息。支持平台按自身政策保留往来内容；如需更正或移除，可通过同一支持渠道提出。

8. 年龄适用性、更新与联系

本应用是通用浏览和媒体工具，并非为儿童设计的服务。请遵守 App Store 显示的年龄分级和地区可用性。仅保存您拥有或已获得来源授权下载的内容，应用不会授予第三方内容的使用权。

政策变化时，我们会更新本页日期。隐私问题请通过公开支持渠道联系。
