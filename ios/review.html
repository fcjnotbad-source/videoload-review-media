Review and testing steps

  1. Enter this page's address in the iPhone app's browser and play the video below.
  2. Tap the app's floating download control, choose the MP4 resource and wait for completion.
  3. Open the downloaded library to check local playback and seeking.
  4. Mark a short clip, such as 2–6 seconds, and use the Pro export feature to create an MP4 or GIF.
  5. Optionally import the same file and test dual view or capture app screenshots.

No app account or access code is required. Test Pro-gated imports, dual view and exports using the normal App Store review or sandbox purchase flow.
