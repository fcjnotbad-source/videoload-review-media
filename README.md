# VideoLoad review media

Public screen recording for the Google Play foreground service permission declaration.

This repository contains review media and its playback page. It does not contain the VideoLoad application source code, signing material, or review access credentials.

The recording demonstrates a user-initiated download, background transfer, ongoing notification, and pausing the download.

Recorded on Android 15 with Play debug build 1.6.9-debug, using the same download service implementation as the Play release. Network speed was limited to make progress observable. The app's legacy label may appear in notifications.

Sample media: https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4 (MDN CC0 video example).
